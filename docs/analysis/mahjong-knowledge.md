# 复盘用规则与定义

适用项目当前四人日麻规则；条件支付以程序结果为准。
Agent 按当前快照与本轮工具选择 dora、structure、melds 条目，不把整份文档附加到每次请求。其他主题保留作维护参考。

## closed：门前、副露与立直

吃、碰、大明杠、加杠会失去门前，之后本局不能立直。暗杠本身不破坏门前。
门前只是立直的必要条件之一，还需要听牌、点数及剩余牌等条件满足。
对手有副露不能证明已经听牌，也不能单凭副露数推出速度或全部打点。

## structure：牌形、向听与有效牌

同花色连续三张数牌可以组成顺子；同花色不等于彼此有连接。
局部搭子和顺子可能共用牌，不能当成能够同时成立的完整拆分。
普通向听下降表示更接近完成牌形，不代表已经有役或能合法和牌。
有效牌是使指定指标推进的牌；不可见枚数包含对手暗牌和死牌山，不是活牌山枚数或摸牌概率。
同向听不代表受入相同；同向听、同受入也不代表整体价值相同。
有效牌的不可见枚数合计只统计数量，没有按宝牌、成形后的搭子质量或打点加权；多一张受入不能单独证明更优。

## melds：副露类型与相对座位

`kind=chi` 是吃，`pon` 是碰；`daiminkan` 是大明杠，用他家弃牌和自己的三张同种牌组成；`ankan` 是暗杠，四张都来自自己；`kakan` 是加杠（也叫补杠），在已有碰上补第四张。
“明杠”包括大明杠和加杠，不能统称为暗杠。吃、碰、大明杠、加杠破坏门前，暗杠本身不破坏门前；牌是否显示在桌面上不能用来判断明杠或暗杠。
`relative_seat_from_self` 的 0/1/2/3 分别是自己/下家/对家/上家。自己只能吃上家弃牌，自己的弃牌只能被下家吃；碰与大明杠没有这个座位限制。

## yaku：役与宝牌

普通日麻和牌需要有役，宝牌和赤宝牌本身不提供役。副露后不能依靠立直或门前清自摸和取得役。
未完成手牌当前没有役，不等于未来无法形成役。当前无役听牌可以通过后续换牌改成有役，须检查实际分支。
字牌中的白、发、中，其刻子或杠子提供相应役牌；对子本身不提供该役。
混一色需要一种数牌与字牌。役种距离相同不能推出完成概率相同。

## dora：宝牌指示牌

数牌指示同花色下一点数，9循环到1。风牌按东、南、西、北、东循环；三元牌按白、发、中、白循环。
指示牌本身不是所指的宝牌。杠后增加指示牌，不能据此认为被杠的牌就是宝牌。
`known_bonus.dora_tiles` 是指示牌对应的宝牌种类；当前持有的宝牌数量不包含未来摸牌带来的价值。
保留宝牌附近的数牌，可能在摸到宝牌后形成搭子或顺子。应结合实际有效牌和牌形检查连接，不能只比较数牌是否靠中间，也不能一律优先保留宝牌靠张。
已知役牌或露出宝牌只提供公开价值依据，不能确定对手暗手总番数与实际支付。

## defense：现物、筋与安全库存

某家自己舍过的牌是针对该家荣和的现物依据，不自动对其他家安全，也不阻止该家自摸。
没有确认安全，不能推成必定危险；筋只是特定等待的线索，不是现物或零放铳保证。
牌数推理必须计入自家暗牌和公开牌；他家鸣牌需要其暗手实际拥有相应消耗牌。
字牌不能组成顺子；排除双碰不代表排除单骑或其他可能牌形。
安全库存逐家统计。相同库存张数不能推出整体防守代价相同，也不是能安全行进的巡数。
吃碰会消耗暗牌，并通常需要再切一张牌；比较时区分鸣牌前、鸣牌后未切牌、鸣牌并切牌后三种状态。

## scoring：分支打点与顺位

不同待牌可以有不同符番与支付。某个待牌的最高支付不能概括其他待牌或路线的预计打点。
指定摸牌后的结果只在给定条件下成立，不能推广为整个策略的收益。
直击目标、荣和其他家、自摸对点差的影响不同；本场、供托须按给定结算计算，不能重复计入。
一次结算后的名次不等于最终顺位；未提供完整终局条件时不能断言比赛结束。

## draw：剩余摸牌与荒牌流局

全场剩余摸牌数不是自家剩余摸牌次数。自家机会取决于轮转、鸣牌、杠和提前结束。
普通荒牌流局中，一至三家听牌时，未听方合计支付3000点、听牌方合计收取3000点；全听或全未听不支付罚符。
给定听牌组合的收支是条件结果，不代表该组合会发生，也不证明现在应保听或弃和。

## evidence：解释的证据范围

Mortal推荐和Q值表达动作偏好，Q不是概率、预期点数或推荐原因。
可以根据事实讨论收益与代价；无法仅凭偏好还原Mortal内部如何权衡。
策略判断需要说明依据和适用条件。证据不够时指出具体缺什么，不能给无依据的说法加“可能”后当作分析。
