# 和牌牌型分解

和牌拆分位于 `src/analysis/agari.rs`，役种检测位于 `src/analysis/yaku/detect.rs`。
拆分层只负责枚举完整和牌的结构，不判断具体役种、等待型或和牌张位置。

## 数据结构

`AgariPattern` 表示一种完整牌型：普通型保存四个面子和雀头，七对子直接保存七个
`TileKind`，国士无双保存重复的幺九字牌。`AgariGroup` 单独表达顺子、刻子和杠子，
并记录明暗信息。

## 分解规则

普通型会递归枚举所有合法的四面子一雀头组合；同一手牌存在多个合法拆分时全部保留，
内容相同的结果会去重。七对子和国士无双只在没有副露且牌数完整时生成。

和牌张位置、荣和刻子与暗刻的特殊判定、等待型以及役种计算不属于当前分解器职责。

## 测试

集成测试位于 `tests/analysis/yaku_patterns.rs`，覆盖普通型歧义拆分、候选去重、七对子
和国士无双。
