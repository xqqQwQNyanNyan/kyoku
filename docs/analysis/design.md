# 分析层：候选取舍事实

本文规定分析内容；实现与性能说明见 [算法方案](algorithm.md)。

Mortal 提供综合动作偏好。程序对双方使用相同口径，计算当前事实、路线差异和明确条件下的结果；Agent 解释这些收益与代价。程序不生成综合策略评分，不预测整局 EV，也不声称已经证明 Mortal 的内部原因。

当前保留17项因素。F14 对手风格、F19 读牌、F20 迷惑、F21 思考／分析时间不在范围内。F06 巡目和剩余摸牌保留；性能仍是工程要求。历史可以用于合法性和已通过牌的校验，不用于推断对手暗手。

## 1. 因素与事实

| 因素 | 实际计算及呈现 | 边界 |
| --- | --- | --- |
| F01 向听数 | 普通／特殊牌形向听与各目标役距离，并列双方差值。 | 相同普通向听不是相同路线；结构距离和已知牌数约束下的距离分开。 |
| F02 搭子结构 | 暗牌中的顺子、刻子、对子、两面／嵌张／边张候选，及同时使用时缺少哪张牌。 | 局部组合不是一套整手拆分；没有两两冲突也不保证多组同时可用。 |
| F03 一向听质量 | 一向听的可用进张后，列出所有到听切牌的待牌、有役条件、振听和支付。 | 不先贴“完全一向听”“良良一向听”标签，也不挑一个好分支代表全部。 |
| F04 改良 | 一次明确摸牌后的全部切牌事实，保留不降低普通向听的路线变化。 | 牌效率摘要仍只有该指标的意义；完整事实比较不按受入删除其他选择。 |
| F05 等待质量 | 待牌种类、未见数、具体拆分等待型、有役和舍牌振听。 | 未见数包含对手暗牌；全部历史荣和限制未重建，不能直接宣称可合法荣和。 |
| F15 打点 | 已知宝牌、役牌刻子条件、具体完成形的符番支付、立直／默听及本场供托结算。 | 未完成路线不输出预计打点；未知里宝牌、事件役不添加。 |
| F10 立直 | 宣言与受理状态、声明条件、1000点支出、条件打点及后续切牌受限。 | 不估计他家对立直的反应；自由摸切分支不用于已立直自手。 |
| F11 副露 | 自家吃碰杠的牌张消耗、门前和路线变化；他家公开面子、役牌与露出宝牌。 | 露出事实不是对手总打点或听牌率。 |
| F12 牌河 | 分家现物、受理立直后已通过牌、筋依据、可见牌排除的具体顺子等待。 | 筋和局部等待排除不等于现物；配对／顺子检查不覆盖国士等全部牌形。 |
| F13 位置关系 | 相对座次、吃牌的下家限制、根据已知牌数尚不能排除的吃碰杠组合。 | 不知道对手是否持有消耗牌、是否会鸣；不解决多家响应竞争。 |
| F16 放铳损失 | 公开价值依据；给定赢家、付款者和符番后的支付与四家点差。 | 符番必须来自具体条件，不由模型补造对手暗牌价值。 |
| F18 防守库存 | 各候选及明确后续分支的分家安全牌、共同安全牌与张数。 | 库存不是还能安全走几巡；后续假设通过的牌单独注明。 |
| F06 巡目 | 各家弃牌次数、历史已知时的摸牌次数、剩余全场摸牌。 | 自家余下机会只在无鸣牌、杠和提前结束的明确条件下计算；G不是巡目。 |
| F07 流局 | 荒牌流局16种听牌组合的3000点罚符、名次、本场供托及继续比赛时的庄家。 | 不预测组合概率；不含途中流局、流局满贯。 |
| F08 供托／本场 | 具体和牌结算中的本场、供托；新增立直支出与回收只记一次。 | 分支净点差相对原快照，不能把自己的立直棒再算一遍收益。 |
| F09 亲子 | 场风自风、庄闲支付和给定流局后的连庄条件。 | 下一局庄家变化以比赛仍继续为条件。 |
| F17 顺位 | 当前点差、具体和牌／流局后的名次与同点顺序；支付门槛和自手打点交叉核对。 | 快照没有完整终局规则，不预测比赛结束或最终名次。 |

支持的21种役种距离不等于21种因素。常规手牌报告计算相同的8种路线；指定役种工具可查询其余已支持路线。役牌另外列当前张数、固定刻子、成刻缺牌和已知枚数；它不是完整手牌到该役的向听。尚未实现的平和等役种距离仍返回明确错误。

## 2. 同一次比较怎样连接事实

默认以同一玩家、同一事件的两个已提供切牌为对象，Mortal 推荐与实际动作使用相同计算，不只为推荐寻找有利证据。公开局况共用；候选各自保留实际赤牌、弃牌后的手牌、役种、等待和安全库存。

例如比较保留混一色与保留普通进张：先并列两种距离及普通受入，指定混一色时再计算推进牌与后续切牌。结合每个切牌的普通向听、进张和安全库存解释代价。相同进张支持多个役不重复算成总收益；不得从某个完成形最高支付推出路线预计价值。

具体摸牌分支完整保留所有切牌事实，不只留下向听最小、受入最大的切牌。已完成牌形另外检查给定普通自摸的有役及支付；不得仅凭向听负一就断言能够和牌，也不得把列出的非和牌切牌读成弃和推荐。

一向听到听事实列出每张可用进张及其所有到听切牌；其他阶段的改良可指定摸牌展开。两种情况都保持他家公开信息不变，不生成真实轮转、摸牌概率或后续策略。

条件结算覆盖利益与损失：自己的和牌可以对照三种放铳者及自摸；给定对手符番可以计算放铳、他家自摸和横移；流局按明确听牌组合计算。每项结果必须连同前提引用，不将条件结果说成当前动作的收益。

## 3. 结果与证据

统一事实入口是 `compare_discard_facts`，其他工具提供聚焦查询。结果包含公开局况、双方事实、机械差值和适用范围；不含综合排名或总体胜率。

`reachable` 和 `shanten` 保留仅看结构的定义；`reachable_with_known_counts` 和 `available_shanten` 另外检查已知牌数上限。可用池仍含对手暗牌和死牌山，后一项只是符合这些数量约束的最小距离，不是实战可完成性的保证。

有数据、条件成立、未检查和不适用必须区分。缺少历史时安全依据可以继续使用直接牌河，其他荣和限制保持未知。终局规则缺失时只给条件点差与当前名次。

工具结果保存在会话历史和执行轨迹中，供后续解释和人工核对。回答直接使用中文和 Markdown，不要求模型复抄证据路径与原始值，不校验段落格式或强制双边引用。解释仍应比较双方事实、区分条件结果和综合倾向；正文正确性通过真实局面验收，不能由输出格式保证。

## 4. 验收

测试覆盖候选交换对称性、普通受入相同但路线不同、混一色必须含数牌和字牌、七对子与国士的牌数约束、赤牌差异、第一次切牌对后续振听的影响、完整保留非受入最佳切牌、分家安全和吃牌座次、立直支出净额、流局资金守恒、给定他家和牌的点差。

既有实际凤凰桌开发案例保存在本地 `tmp/houou-research/analysis-cases.md`，不是代表性统计样本或最优动作标签。开发案例中“同向听不同路线”“无役听牌”“保听与撤退条件”的要求继续适用；完整四家模拟、事件概率模型与统一EV不再作为实现前提。
