# 日麻牌面

素材来自 [FluffyStuff/riichi-mahjong-tiles](https://github.com/FluffyStuff/riichi-mahjong-tiles)，
使用 `Regular/` 中的 34 种牌、3 种赤五和牌背。
固定版本：`26e127ba2117f45cdce5ea0225748cc0cfad3169`。

原作者以 [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/) 发布，
原始许可见 [LICENSE.md](LICENSE.md)。SVG 保留原始图案，移除了编辑器元数据；
牌体背景、厚度和交互高亮由 `style.css` 绘制。白板采用日麻的空白牌面。

资源随应用打包，运行时无需联网，也不依赖系统中文字体。
